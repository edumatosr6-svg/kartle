# Divergências

F-Spec (3.2.0) é normativo: nenhuma linha abaixo enfraquece um requisito. Cada linha cita o que existe hoje
em `arquivo:linha` — a árvore depois da rodada de código 1, que escreveu parte do projeto anterior —, a
etapa que deve a mudança e o item de projeto que a fecha. Caminhos relativos à raiz do repositório.
