## Padrão de Cada Agente

### Propósito
Descrever o objetivo principal do agente.

### Skills Associadas
Listar as skills que o agente utiliza.

### Quando Ativa
Descrever em quais situações o agente é acionado automaticamente.

### Comportamento
Descrever como o agente se comporta e suas responsabilidades.

Para adicionar um novo agente, consulte o template em `.template.md`.
