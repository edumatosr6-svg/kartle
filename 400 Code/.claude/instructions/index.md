# Instruções Centrais do Projeto

## Visão Geral

Este diretório contém todas as instruções centrais que guiam o comportamento do Claude ao trabalhar neste projeto.

## Arquivos de Instrução

### [system.md](./system.md)
Define o comportamento geral do sistema, hierarquia de decisão e estrutura de resposta.

### [guidelines.md](./guidelines.md)
Padrões de código, formatação de resposta e configurações específicas do projeto.

### [context.md](./context.md)
Contexto do projeto: arquitetura, stack tecnológico, estrutura do repositório, pessoas e restrições.

### [protocols.md](./protocols.md)
Protocolos de comunicação e procedimentos padrão.

## Como Usar

1. Leia todas as instruções para entender o contexto
2. Siga as guidelines ao desenvolver
3. Respeite os protocolos estabelecidos
4. Consulte o context quando tiver dúvidas sobre arquitetura
