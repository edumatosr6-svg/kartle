# Kart 01 — código do modelo

Pasta para o código Three.js que monta o **Kart 01**, criado no chat do Cowork
(ficha de design: https://claude.ai/artifact/TbeRnYeqGfw89rg3nLQYGX).

Salve aqui, como veio do Cowork:

- o arquivo `.js`/`.ts` que monta o modelo (grupos nomeados: `chassi`, `eixoTraseiro`,
  `rodaDianteiraEsq/Dir`, `rodaTraseiraEsq/Dir`, `nariz`, `painelFrontal`, `sidepodEsq/Dir`,
  `paraChoqueTraseiro`, `banco`, `direcao`, `pedais`, `motor`, e o grupo do piloto);
- qualquer textura ou adesivo que ele use (`01`, `KARTLE`).

Convenção da ficha: 1 unidade = 1 m; origem no chão, no meio do entre-eixos;
frente −Z, direita +X, cima +Y. Câmera de jogo: 1,38 m acima, 3,05 m atrás,
mira 3,2 m à frente a 0,30 m do chão, FOV vertical 62°.
